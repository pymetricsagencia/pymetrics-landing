# Pymetrics — Landing

Landing page de **Pymetrics** (agencia de procesamiento de datos para pymes).

- **Sitio en vivo:** https://pymetrics-landing.vercel.app
- **Hosting:** Vercel (proyecto `lenrik-2011s-projects/pymetrics-landing`)
- **Archivo:** `index.html` — sitio estático de un solo archivo (sin build). Usa Google Fonts y Chart.js vía CDN.

## Cómo actualizar el sitio

1. Editar `index.html`.
2. Publicar a producción:

   ```bash
   vercel deploy --prod
   ```
